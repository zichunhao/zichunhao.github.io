# zichunhao.com

Personal academic website of [Zichun Hao](https://zichunhao.com), Ph.D. candidate in physics at Caltech working on machine learning and experimental high energy physics at the CMS experiment.

## What's here

- **[About](https://zichunhao.com/)** — research overview and background
- **[Publications](https://zichunhao.com/publications/)** — papers with dedicated pages, abstracts, and BibTeX
- **[News](https://zichunhao.com/news/)** — paper announcements and talks
- **[CV](https://zichunhao.com/cv/)** — full academic CV with a downloadable PDF

## Built with

The site uses the [al-folio](https://github.com/alshedivat/al-folio) Jekyll starter (MIT license). Content lives in `_pages/`, `_bibliography/papers.bib`, `_news/`, and `_data/`. GitHub Actions builds the site to the `gh-pages` branch and GitHub Pages serves it at the custom domain.

## Local development

```bash
bundle install
bundle exec jekyll serve
```
